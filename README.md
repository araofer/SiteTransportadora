# 🚚 Transportes — Site Institucional

Website institucional moderno, performático e 100% responsivo desenvolvido para a empresa **Transportes & Gestão Logística**.

---

## 🚀 Tecnologias Utilizadas

- **React** — Biblioteca para construção de interfaces
- **Vite** — Build tool ultra-rápida para desenvolvimento frontend
- **Tailwind CSS** — Framework CSS para estilização ágil e responsiva
- **Lucide React** — Biblioteca de ícones modernos

---

## ✨ Funcionalidades e Diferenciais

- 📱 **Design 100% Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
- 🎨 **Header Dinâmico:** Alteração visual suave ao rolar a página (*scroll*) e menu mobile com cobertura total de tela.
- 👁️ **Leitura Otimizada:** Seções com sobreposição (*overlay*) escura para garantia de alto contraste e acessibilidade.
- 📍 **Seção de Contato:** Exibição completa de dados de atendimento e integração de localização.
- 📋 **Formulário de Orçamento:** Interface intuitiva para captação de novas propostas logísticas.
